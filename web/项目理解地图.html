1 这个网站是干什么的？

先搞懂"产品是什么"，再搞懂"代码怎么组织的"。

🤖
一句话版

这是一个「AI 帮你批改编程作业」的学习平台——学员上传代码文件（.cpp / .java），系统交给 AI 批改打分、指出错误，再通过图表展示学习情况。

🛠️ 用到的"积木"（技术栈）
Vue 3 页面框架 Vite 开发工具 Vue Router 网址导航 Pinia 全局记事本 Axios 发请求的快递员 Element Plus 现成 UI 组件 ECharts 画图表
💡 翻译成人话：这些"积木"都不用你自己造，Vue 负责搭页面、Router 负责换网址页面、Pinia 负责记住登录状态、Element Plus 负责好看的按钮和表单、ECharts 负责画饼图折线图。

3 每个页面的"人话版"思路卡

每个有用的页面一张卡：它是干嘛的、能看到什么、点了按钮会发生什么。

🔑

登录 / 注册页

/login
🆓 不用登录就能进
全站的"大门"。左边是品牌介绍（AI 批改、错题本、学习报告三大亮点），右边是表单。访问需要登录的页面但没登录时，会被自动送到这里。
📝 能操作
  • 登录：填邮箱 + 密码
  • 注册：邮箱 + 用户名 + 密码(8-16位) + 确认密码 + 选角色（学员/老师）
🔍 背后的逻辑
📝 填表单→ ✔️ 前端校验(格式/两次密码)→ 📦 发给后端→ ✅ 登录成功：存"门票"token→ 🏠 跳首页
注册成功后会自动切回"登录"标签，并帮你把邮箱填好，直接输密码就能登录。失败时：密码错提示"邮箱或密码错误"，邮箱被注册过提示"该邮箱已被注册"。

📝 能操作

4 幕后小助手（代码是怎么协作的）

这些不是页面，而是帮页面干活的后台模块。都用"人话比喻"讲。

🚀

点火开关 main.js

整个项目的"开机程序"。它创建应用，并装上三样东西：导航（Router）、全局记事本（Pinia）、UI 组件库（Element Plus）。装好后把应用挂载到网页上。

🗺️

导航地图 + 保安 router/index.js

一张"网址 ↔ 页面"的对照表。同时还是个保安：去需要登录的页面，先查你有没有"门票"（token），没有就把你请到登录页；已经登录还去看登录页，会直接送你回首页。

📔

全局记事本 stores/user.js

记录登录信息（token、邮箱），所有页面都能读。登录成功就写进去，退出就清空。它把信息同步存到浏览器本地（localStorage），所以刷新页面也不会掉线。

📦

快递员 utils/request.js

所有发给后端的请求都走它：自动在包裹上贴"门票"（token），超时 10 秒自动放弃。它是前后端之间的统一通道，页面不用自己拼地址。

📋

快递单 api/*.js

每个接口一张"快递单"，页面只需要调用写好的函数（比如 loginApi(邮箱, 密码)），不用关心地址怎么写。目前有两张：user.js（登录/注册）、submission.js（上传作业）。

🧱

页面积木 views/*.vue

每个 .vue 文件 = 一个页面（第 3 章讲的那些）。它们负责"长什么样 + 用户点按钮后干嘛"，需要用数据时就喊快递员去后端取。

🔁 一次完整操作的"数据旅行"（举例：点登录按钮）
🖱️① 你点按钮登录页
→
📦② 快递员出动request.js 自动贴门票
→
🖥️③ 后端处理/api/login 校验账号
→
🎫④ 拿到门票存进记事本+本地
→
🏠⑤ 跳转首页带着登录状态
💡 前端(浏览器)负责①②④⑤ 🖥️ 后端(另一台电脑)负责③ 🌉 开发时通过 /api 代理转发到 localhost:8080

6 给队友的"注意事项"

接手的队友最需要知道的几件事，都总结在这里。

  • 🎫
    "门票"就是 token：登录后后端返回一个 token，存在浏览器本地（localStorage）。它是"你已登录"的凭证，很多接口都要带上它，后端才认你。
  • 🧪
    哪些是"真接口"，哪些是"假数据"：真正连了后端的只有 3 个——登录、注册、上传作业。首页的数据卡片 / 最近提交、报告页的全部图表、个人中心的学习数据，目前都是写死的演示数据。
  • 📁
    昵称保存是"半成品"：个人中心改昵称目前只存到浏览器本地，代码里留了注释"等后端接口好了再对接"，属于待完成项。
  • 🚧
    几个"开发中"占位：错题本、历史提交、修改密码这几个功能入口/按钮目前点了只弹提示，页面还没做。
  • 🚀
    怎么把网站跑起来：需要先在项目目录装依赖再启动（见下面命令）。注意后端也要在 localhost:8080 跑起来，否则登录/上传会失败。
  • 🛡️
    页面保护机制已经搭好：新加"需要登录的页面"只需在路由里加一行 meta: { requiresAuth: true }，保安会自动拦人，不用自己写判断。
